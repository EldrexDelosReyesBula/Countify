Countify+ v2.0.29 Release
Welcome to Countify+ v2.0.29! This release introduces significant improvements to text management, voice features, and overall user experience. Explore the new capabilities below.

Release Date: November 8, 2025, 2:20pm Philippines official release

Note: Some features are in beta and may encounter occasional issues as we continue development.

Core Text Management

Enhanced text analytics and formatting capabilities

Overview

Completely redesigned text management system with real-time analytics and advanced formatting options.

Key Features

  • Real-time word, character, sentence, and paragraph counting
  • Comprehensive statistics including reading time, speaking time, and unique words
  • Automatic saving every 3 seconds with visual indicators
  • Text Formatting: Uppercase, lowercase, title case, and sentence case transformations
  • Text Cleaning: Remove extra spaces and reverse text functionality

Voice & Input Features

Advanced voice recognition and intelligent punctuation

Overview

Enhanced voice input with intelligent punctuation and real-time visual feedback.

Key Features

  • Voice Dictation: Speech-to-text with real-time transcription
  • Puncify (Intelligent Punctuation): Automatic sentence capitalization and punctuation (Beta)
  • Voice Visualizer: Animated audio feedback during voice input
  • Voice Controls: Start, pause, stop, and space insertion commands

Activity Management

Enhanced organization and workflow improvements

Overview

Streamlined activity creation, organization, and management with new archive and recovery systems.

Key Features

  • Activity Creation: Quick creation with smart default titles (Morning/Afternoon/Evening)
  • Activity Organization: Dashboard, Today's, Yesterday's views
  • Archive System: Temporary storage for inactive activities
  • Recycle Bin: Deleted activities recovery system
  • Duplicate Function: Quick activity copying with "(Copy)" suffix

Search & Navigation

Enhanced discovery and navigation experience

Overview

Improved search functionality with real-time filtering and enhanced navigation.

Key Features

  • Full-screen Search: Comprehensive search across all activities
  • Real-time Filtering: Instant results as you type
  • Search History: Recent search queries and results
  • Smart Navigation: Drawer-based app navigation with active state indicators

Editor Enhancements

Improved text editing with advanced features

Overview

Enhanced text editor with improved history, formatting, and import/export capabilities.

Key Features

  • Undo/Redo: 50-step history with visual button states
  • Text Import/Export: TXT and Markdown file support
  • Real-time Analytics: Live updating statistics panel
  • Format Preservation: Clean paste functionality removing formatting (beta)
  • Auto-formatting: Smart text correction and formatting (beta)

Integration Features

Cross-app connectivity and sharing capabilities

Overview

Enhanced connectivity with other applications and improved data sharing capabilities.

Key Features

  • LanLink Integration: Secure text transfer to LanWord editor (beta)
  • Cross-app Sharing: Browser-based data transfer protocol
  • Service Worker: Progressive Web App capabilities
  • URL Handling: Deep linking and hash-based navigation (beta)

Advanced Analytics

Comprehensive writing insights and productivity tracking

Overview

Enhanced analytics with visualizations and detailed productivity metrics.

Key Features

  • Writing History: 7-day visual word count graph
  • Productivity Stats: Words per minute, longest activity, most productive day
  • Writing Streak: Daily writing habit tracking
  • Performance Metrics: Average words per activity, total writing time

Professional Features

Enhanced compliance and documentation

Overview

Professional-grade features with enhanced compliance and documentation.

Key Features

  • Version Tracking: Clear version numbering (2.0.29)
  • License Compliance: LPSL v1.0 licensing
  • Documentation: Terms of service and privacy policy links
  • Professional UI: Material Design icons and consistent styling

Security & Privacy

Enhanced data protection and privacy controls

Overview

Enhanced security measures and privacy-focused data handling.

Key Features

  • Local Data Only: No cloud storage or data transmission
  • Secure Transfers: LanLink signature verification
  • Data Cleanup: Automatic temporary data removal
  • Privacy Policy: Transparent data handling
